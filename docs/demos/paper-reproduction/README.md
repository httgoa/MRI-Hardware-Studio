# MRI Hardware Studio · Fractionated Dipole walkthrough

Open `index.html` directly in Chrome or Edge. The public demo is self-contained under this directory; no build step or web server is required.

The reference study is Raaijmakers et al., *Magnetic Resonance in Medicine* 75:1366–1374 (2016). Comparison panels are presented for scientific validation and remain attributable to the cited publication.

## Recording flow

1. Open the page and optionally enter fullscreen.
2. Click **Begin walkthrough**.
3. Scroll to each stage and click its reveal button.
4. Stage 03 contains the complete Fig. 3 and Fig. 4 modeling/sweep evidence; continue scrolling after revealing it.
5. In Stage 04, switch between Fig. 3 / Fig. 4 and reproduction / paper comparison.
6. Use **Reset** or press `R` before recording another take.

Keyboard shortcuts: `F` toggles fullscreen; `R` resets the walkthrough.

For a deterministic review entry, append `#stage-03-reveal` (or the corresponding stage ID). The older zero-based query form, such as `?stage=2&reveal=1`, is also supported.
