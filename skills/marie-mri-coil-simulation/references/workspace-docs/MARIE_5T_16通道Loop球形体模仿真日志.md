# MARIE 5 T 16通道 Loop 球形体模仿真日志

## 1. 日志规则

- 项目：5 T、氢核、直径约 200 mm 均匀球形体模、16 通道双排 Loop 纯接收阵列。
- 固定几何：`R115/H90/Span50/Z25/Stagger22.5`。
- 拉莫尔频率：212.88739259 MHz。
- Stage A 生成一次原始 `YPn`；Stage B 反复复用同一 `YPn` 优化 TMD。

- 从下一次成功运行开始，`RUN_5T_16CH_TMD_ONLY.m` 会自动在本文件末尾追加完整数值记录。

## 2. 已完成过程

### 2.1 16通道几何与端口检查

结果：三维几何成功生成，16 个 Loop 采用上下双排、方位角错位 22.5°。导线轴向范围保持在约 `z=[-70,+70] mm`，可继续使用同一 `R115/H140` 连续圆柱支撑面的 UISNR 基准。

已验证：

- 16 个物理端口；
- 每通道一个 port 和七个分段元件；
- `excitation.entity` 与通道号一致；
- 结果 `SP_s` 为 `16x16`；
- `h_field.Rx.b1m` 第四维为 16。

### 2.2 初始独立 TMD 分组错误

现象：优化后出现明显的奇偶通道交替，部分通道失谐或浅匹配。上排奇偶通道 B1- 能量比约为 1.3703，下排约为 1.0665。

原因：直接给每通道设置表面上不同的 `optim.symmetry`，仍可能在 MARIE 内部经过端口网络偏移后发生 ID 碰撞。最初使用包含重复分组的检查方法还会把同一 Loop 内七个本应共享的分段电容误报为冲突。

处理：

- 每个 port 网络使用独立且留有足够间隔的 symmetry 基值；
- 每个 Loop 的七个分段电容在本通道内共享一组；
- 不同通道之间不共享分段电容组；
- 分别检查 48 个 port 内部变量、16 个分段电容变量以及两类变量之间是否重叠。

结论：内部 TMD symmetry 冲突已消除。

### 2.5 损耗感知 minimax TMD

代码修改：

- 新增有限 Q 的逐粒子前放加载评估；
- 目标改为最小化最差通道归一化反射系数；
- JSON 元件上下界作为最终阶段硬约束；
- 原版 MARIE 函数保留，使用 `useLossAwareTMD` 切换。

首次运行曾报告：

```text
函数或变量 'co_simulation_Rx_optim_loss_aware' 无法识别
```

原因是新增的三个函数尚未同步到 Linux 相同相对目录。同步文件并执行 `clear functions; rehash path; startup;` 后恢复运行。

最新截图观察：

- 原来约 `-10 dB` 的失败通道族改善到约 `-16 dB`；
- 图中全部 16 个 `SP_p` 柱均低于 `-15 dB` 目标线；
- 各通道频率扫描谷值集中在 212.887 MHz 附近；
- 部分原本很深的匹配变浅，同时最差通道改善，符合 minimax 目标的预期；
- 端口 2/4/6/8 的截图估计裕量约为 1 dB，属于通过但鲁棒性有限。

待补充：本轮终端输出的精确 `runTag`、最差 `SP_p`、匹配裕量、最大频偏和最差互耦。只有 `Match / resonance / coupling pass: 1 / 1 / 1` 时，才能正式冻结该轮电路。

### 4.2 结论

匹配、谐振和互易性通过，损耗感知 minimax 已解决此前的通道族浅匹配问题。互耦未通过，且瓶颈位于下排内部相邻端口 9/10；跨排耦合反而达到 -15.312 dB。因此本轮不能作为正式 Stage C 最终候选。

重复运行相同 TMD 设置预计不会系统改善 `S10,9`，因为当前损耗感知代价函数只约束逐通道 `SP_p`，没有把非对角 `SP_s` 加入优化目标。下一步先比较多个 TMD 轮次中 `S10,9` 是否稳定，再决定是增加电路互耦惩罚，还是返回几何外层扫描。若不同电路轮次均接近 -10 dB，应判定为几何主导并优先调整同排 Loop 的方位跨度/重叠。

固定几何和固定 `YPn` 下，`S10,9` 随电路状态在 `-15.005` 到 `-9.732 dB` 之间变化，幅度超过 5 dB。早期电路轮次满足 `< -12 dB` 互耦门槛，而后期以匹配为唯一 minimax 约束的轮次逐步恶化。因此不能把当前 `S10,9` 失败直接判定为几何不可改善；主要证据指向 TMD 目标函数的权衡。

下一步优先在有限 Q 的联合目标中同时约束：

```text
所有端口 SP_p < -15 dB
所有非对角 SP_s < -12 dB
```

只有联合目标在合理元件边界内仍无法同时通过时，才转入几何外层扫描。相同设置的重复轮次已经成对得到完全一致结果（053238/053902、061744/063923），说明继续重复当前目标没有意义。
